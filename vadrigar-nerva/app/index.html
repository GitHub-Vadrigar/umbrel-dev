Node Configuration

Adjust node preferences below. Saving these settings will automatically restart the backend services.

Enable QuickSync QuickSync can save hours of initial synchronization time. When disabling QuickSync, the blockchain will be downloaded and verified entirely from the genesis block (slower, maximum security).
Priority Node IP (Optional) If running multiple Nerva nodes on the same network, enter the IP of your main node to prevent sync issues.
Exclusive Node IP (Optional) With exclusive node, you can't connect to other nodes so you'll use your main node as a relay.
Log level By default nervad creates a nerva.log in the Nerva data directory. Adjust the verbosity of nervad to suit your node's needs. Level 0 is the default and least verbose, while level 4 is highly verbose and ideal for debugging.
Disable UPnP on Node Disable UPnP port mapping.
Disable Analytics Do not submit any analytical information to hide from the node map.
Hide Port Do not announce your node as peerlist candidate.
